# FoxOsis — тутор

Приватный P2P-мессенджер: сообщения, звонки и файлы идут **напрямую между
устройствами** — без серверов аккаунтов и слежки. Название — только **FoxOsis**.

---

## 1. Быстрый старт (браузер)

```bash
node server.js
```

Открыть **http://localhost:8099** в Chrome или Edge.

1. Стрелочка в шарике → «Регистрация»: Имя, @юзернейм, пароль.
2. Нажать «Создать аккаунт» — готово.
3. Слева кнопка **✎ Новый чат** → ввести @юзернейм собеседника → он найдётся,
   если в сети. Клик — чат откроется, соединение установится само.

> Юзернейм — ваш адрес: по нему (и по номеру телефона) вас найдут в любом городе.

## 2. Сообщения

- Отправка: Enter или кнопка-стрелка.
- Галочки: ✓ — доставлено, ✓✓ — прочитано.
- Собеседник не в сети — сообщение ляжет в чат и **ушлёт ему push**, когда
  он откроет мессенджер (или он увидит уведомление сразу).

## 3. Вложения (картинки, видео, файлы)

Кнопка **📎** слева от поля ввода → выбрать файл(ы).
Изображения автоматически сжимаются (до 1000px), лимит файла — 300 КБ.
Картинка в чате открывается кликом, видео — плеером, остальное — ссылка-скачать.

## 4. Звонки

В открытом чате — кнопки **телефон/видео** в шапке чата.

- Собеседник в сети: звонок идёт сразу.
- Не в сети: уходит **push-уведомление о звонке**, он открывает приложение —
  соединение устанавливается, звонок стартует.
- Входящий звонок: экран с кнопками **Принять / Отклонить**; при закрытой
  вкладке — уведомление ОС с кнопками **Принять / Сбросить**.

## 5. Push-уведомления (браузер) — работает

При первом входе браузер спросит разрешение → «Разрешить».

- Chrome/Edge → FCM/WNS доставляют уведомление, даже если **вкладка закрыта**.
- Проверить: **Настройки → Уведомления → Показать тест-уведомление**.
- Управляется там же: «Выключить/Включить».

Что под капотом: Web Push (VAPID + RFC 8291 aes128gcm), шифрование сверено с
референсом `http_ece`; прокси `/api/push` в `server.js` нужен, потому что WNS
не отдаёт CORS; подписка хранится в Nostr (`foxosis/v2/push/<ник>`).

## 6. Настройки (новая кнопка-шестерёнка в шапке)

| Вкладка | Что внутри |
|---|---|
| **Профиль** | переход в профиль, @юзернейм, Peer ID + копирование |
| **Уведомления** | статус пуша, вкл/выкл, тест-уведомление |
| **О приложении** | версия, число релеев/собеседников/p2p-соединений, журнал событий |

## 7. Профиль: телефон и обложка

Профиль (кнопка-человек в шапке):

- **Телефон** — ввод с автоматическим форматом `+7 (999) 123-45-67`.
  Номер публикуется в Nostr — **по нему вас найдут поиском** (введите цифры
  в строку поиска у собеседника, и ваша карточка появится).
- **Обложка** — клик по гранёной шапке карточки выбирает фото (сжимается).
- **Аватар** — клик по кругу.

## 8. Email-коды при регистрации (опционально)

В форме регистрации: email → «Получить код» → 6 цифр вставляются в поле →
«Создать аккаунт».

- Режим без SMTP (`node server.js`): код показывается прямо в поле (dev).
- С SMTP-окружением — код уходит письмом. Хранение кодов: память сервера,
  10 минут, 5 попыток, анти-спам 1 код/мин.

## 9. APK (Android)

```bash
npm install
npx cap sync android          # копирует www/ в Android-проект
cd android && gradlew assembleDebug
```

APK: `android/app/build/outputs/apk/debug/app-debug.apk`

**Важно честно:** в APK работает всё, кроме push при **закрытом** приложении —
Capacitor WebView не поддерживает Web Push. Звонок/сообщение видны, пока
приложение открыто или в фоне. Чтобы уведомления шли при закрытом приложении,
нужен FCM: положи `google-services.json` от Firebase — подключу.

## 10. Где что лежит

| Файл | Назначение |
|---|---|
| `app.js` | всё приложение (чанки сжаты brotli, E2EE-шифры) |
| `index.html` | разметка + весь CSS |
| `sw.js` | Service Worker: приём push, уведомления ОС, кнопки звонка |
| `server.js` | dev-сервер: статика + `/api/push` + `/api/email/*` + WS-ретранслятор |
| `api/push.js` | тот же форвардер пуша для Vercel |
| `www/` | то, что уходит в APK (`npx cap sync android`) |
| `scripts/bundle.mjs` | сборка `app.bundle.js` (esbuild) |

После правок `app.js`/`index.html`/`sw.js`:

```bash
node scripts/bundle.mjs
# и скопировать в www (для APK):
# app.bundle.js, index.html, sw.js → www/
```

## 11. Тесты

Автотесты (Puppeteer) лежат отдельно от репозитория. Наборы: полная регрессия
(два клиента, чат, галочки, вложения, настройки, телефон, звонок, перезагрузка),
push E2E (Chrome и Edge), email-коды, сверка шифрования с `http_ece`.

## 12. Ограничения и особенности

- **Лимитов нет**: без подписок, платы и лимитов использования.
- Публичные Nostr-релеи — чужие и бесплатные; часть требует регистрации или
  отклоняет анонимные публикации. Приложение автоматически работает через
  остальные (в списке их 12). Свой релей = одна строка в `CFG.NOSTR_RELAYS`.
- Пароль и ключи хранятся **только на устройстве** (SHA-256 в localStorage) +
  продублированы в «облаке» (Vault) по паролю — для входа с другого устройства.
- VAPID-ключ приложения лежит в клиенте — осознанный компромисс serverless-режима.
